 FA-01  Bestellung wird im ERP mit Lager, Bestellung, Rechnung gebucht
 ----------------------------------------------------------------------------
 gns3@SRV-ERP:~$ sudo techtrade inspect
 gns3@PC1:~$ curl -s -i -X POST http://shop.techtrade.lab:8080/orders \
               -H "Content-Type: application/json" -H "X-Request-ID: g3-001" \
               -d '{"sku":"KB-01","qty":1,"customer":"Muster"}'
             Erwartet: HTTP/1.0 201 Created, order_id, total_chf 79
 gns3@SRV-ERP:~$ sudo techtrade inspect
             Erwartet: KB-01 Lager −1, 1 Bestellung, 1 Rechnung CHF 79
 gns3@SRV-WEB:~$ sudo journalctl -u techtrade-shop | grep g3-001
 gns3@SRV-ERP:~$ sudo journalctl -u techtrade-erp | grep g3-001
             Erwartet: je eine Zeile mit "status": 201

 FA-02  Mengen ausserhalb 1–99 → HTTP 400; über Lagerbestand → HTTP 409;
        in beiden Fällen keine Buchung
 ----------------------------------------------------------------------------
 gns3@SRV-ERP:~$ sudo techtrade inspect
 gns3@PC1:~$ curl -s -i -X POST http://shop.techtrade.lab:8080/orders \
               -H "Content-Type: application/json" -H "X-Request-ID: g3-010" \
               -d '{"sku":"MS-01","qty":0,"customer":"Test"}'
             Erwartet: 400
 Den Befehl in dieser Reihenfolge wiederholen (jedes Mal neue X-Request-ID):
   "qty":100      Erwartet: 400
   "qty":"abc"    Erwartet: 400
   "qty":41       Erwartet: 409 (MS-01 hat 40 Stück)
   "qty":99       Erwartet: 409 (gültige Menge, Lager reicht nicht)
   "qty":1        Erwartet: 201 (MS-01 danach 39)
   "qty":39       Erwartet: 201 (genau der Restbestand, MS-01 danach 0)
 gns3@SRV-ERP:~$ sudo techtrade inspect
             Erwartet: Buchungen nur für die Fälle mit 201

 PERF-01  Shop bestätigt eine Bestellung in ≤ 2 s
 ----------------------------------------------------------------------------
 gns3@PC1:~$ time curl -s -i -X POST http://shop.techtrade.lab:8080/orders \
               -H "Content-Type: application/json" -H "X-Request-ID: g3-020" \
               -d '{"sku":"KB-01","qty":1,"customer":"Muster"}'
             Erwartet: HTTP 201, "real" deutlich unter 2 s
 Zeit je Phase (vertikal):
 gns3@PC1:~$ curl -s -o /dev/null -w "dns=%{time_namelookup} tcp=%{time_connect} total=%{time_total}\n" http://shop.techtrade.lab:8080/products
